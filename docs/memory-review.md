# 记忆收纳与确认（2026-10-28）

“有证据的记忆”区域默认收起记忆库，首页只显示待核对/已确认数量。展开后可切换分类、搜索、分页，每页最多 10 条摘要；原文和更正操作默认折叠。设置特别关注的表单也改为折叠入口。

点击“✓ 确认正确”确认当前版本，记录移出待核对列表，保留在已确认分类。确认不删除原文、记忆和证据，不关闭关注或通知，不影响 AI 检索；确认之前也仍可参与现有自动关联流程。可以“移回待核对”。

确认记录持久保存在本机数据库，重复导入同一记忆不会重置确认。更正生成的新记忆需要重新核对；原文修订使旧记忆失效，旧确认不会作为有效确认继续显示。界面操作带预期版本，拒绝对过期内容确认。

数据库升级至版本 18，仅新增 memory_review 表，没有批量替用户确认任何内容。升级前备份位于 data/backups/before-memory-review-*.sqlite3。

验证：146 项 Python 测试通过，包含确认后仍可被关联召回、重启持久、重复导入、来源变化、100 条以上分页。浏览器验证覆盖默认收起、证据折叠、确认移出/切换分类/移回、更正后重新核对以及窄屏布局。
