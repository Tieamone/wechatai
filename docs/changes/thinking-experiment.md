# 思考模式对比：待授权方案

本方案与脚本的交付不包含真实调用。默认执行 `python -m tools.thinking_experiment` 只读生成清单，窗口与结果只留本机。后续须用户明确同意清单和预算，再传 `--execute-approved-manifest 清单SHA256`；本轮不传此参数。

固定模型 deepseek-v4.1-flash-1017、提示词 extract-v2-zh、JSON Object 格式及 max_tokens=4096，仅改变 default（不传思考参数，不声称等同于显式开启）和 off（顶层 enable_thinking:false）。角色处理始终关闭，合同和隐私替换沿用生产路径；只读重校验不创建记忆、证据、请求或人工标注。未来执行时为防重复花费，只写必要的用量账本、批量预算记录及本机试验文件，不改磁盘模型配置、价格或日常提示词。

四个不同窗口：从冻结集内，按 job_id 顺序依次选取一个 v2 曾发生 D304、一个 v3 空结果、一个 v3 非空结果；第四个取剩余窗口按消息数及 ID 排序的中位窗口。选择与质量无关，不代替价值标注。前三类即使重合也选择不同窗口以保留覆盖。前两窗口为重复测量样本。

首轮每窗 default/off 各一次，顺序在相邻窗口反转，共 8 次；前两窗再以各自相反顺序重复两种配置，共 4 次，总计最多 12 次。整轮硬上限 40,000 Token，预留不足会提前停止，并非保证能跑满 12 次。创建 receipt 和运行前先预检全局、批量比例与单轮预算；预检不足没有调用和运行占位。文件存在不等于已花费；仅当本清单已有 usage_ledger 调用记录才禁止同清单重试，没有任何调用记录可复用清单重试。沿用已启用的滚动全局预算及批量比例，不抬限、不清账本。用量未知、参数拒绝或其他失败立即停止，不回退、不自动重试。进入下一忙闲时段也停止，以减少价格混淆。要求工作台、采集、机器人均已停止，脚本获取三个互斥锁；不自动停止用户程序，不自动迁移数据库。

每次记录输入、输出、推理明细，候选数、D304 次数、耗时、配置指纹、重复编号及可见输出文本与字节数。供应商 text_tokens 不被当成固定含义的可见输出 Token；可见输出 Token 数无法核验时保持未知。推理缺失不是零。缓存命中、顺序效应和供应商默认思考行为仍可能影响结果，因此保留明细、不直接归因为思考模式。重复次数仅用于观察随机差异，不构成统计显著性证明。

材料只给并排输出，不自动判定质量；用户分别判断准确性和长期价值。费用仍按公开原价估算，未核对账单，价格填写和真实执行授权均待用户决定。
