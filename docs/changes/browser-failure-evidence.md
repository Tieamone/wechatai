# 合成浏览器测试诊断

隐私预览测试在点击前注册 POST /api/privacy/preview 响应等待，确认 HTTP 成功且 JSON 已读取后再断言页面状态，不增加固定睡眠或断言超时，不改变应用逻辑。

工作台、上下文、P0、预算、离线校准五个合成场景开启 Playwright trace；断言或运行错误时尽力保存 failure.png 和 trace.zip，然后继续抛出原错误。文件写入 test-artifacts/ 对应场景目录，已忽略，不进入源码提交。仅测试入口启用，不能用于真实聊天页面。

CI 失败时使用固定提交的 upload-artifact 上传该目录，保留 7 天；非浏览器步骤失败而无文件时只提示。trace 可能含测试页面和请求，只允许使用隔离合成数据，不上传 data/ 或 private/。自检使用 setContent 的静态合成页面验证 PNG/ZIP 文件头并删除产物，不故意让 CI 失败。

本地可以验证采集和测试流程；GitHub 在真实失败任务中的附件下载需未来实际失败时验证，不人为制造 main 失败。应用启动失败、浏览器启动前或 Python 进程超时等早期故障可能没有截图和完整 trace，仍依赖任务日志。
