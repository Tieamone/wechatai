# 两段式记忆设计：收窄版草案

日期2026-11-03。本版替代此前宽范围设计，只改文档；不实施状态机、解析器或模型配置，不升级真实库、不调用模型。两份提示词须审阅确认后才可使用。

## 当前行为与临时保护

现有完整性状态 active/stale/incorrect/superseded，memory_review 独立保存人工确认版本；temporal_kind 是 preference/plan/past_event/fact/unknown，不是长期/短期。job 的 validated_model 仅表示提炼提交，不代表语义审核通过。

独立临时闸门限制依赖记忆的主动工作：仅当前版本人工确认才可关联入队和发送；绑定未确认记忆的关注保留设置、暂停触发，纯关键词关注继续。搜索和用户主动回忆不受影响。文档提交不悄悄启用运行逻辑。

## 三阶段范围

| 阶段 | 内容 |
| --- | --- |
| 1 | 候选表、AI审核记录、生命周期字段、统一资格函数；粗提/审核各一份模型配置；本机日期规则 |
| 2 | 约定到期提醒、提醒现场反馈、每周抽检、自动降级 |
| 3（可选） | 免费额度模型池、每模型参数和额度交接 |

阶段1不建 model_profile 或模型池。每阶段尽量一次迁移，沿用停写锁、空间检查、在线备份和恢复验证。本轮不修改schema_version。

## 阶段1：状态和迁移

候选单独保存，不写普通FTS，不参与搜索、召回、提醒；精修通过后单一事务创建正式记忆、完整证据、审核来源和生命周期。rejected留审计，expired不删除。人工confirmed与AI审核分开。

| 状态 | 搜索/回忆 | 主动资格 |
| --- | --- | --- |
| candidate | 否 | 否 |
| rejected | 专门审计详情 | 否 |
| ai_reviewed | 是 | 按统一证据、风险、期限与通知策略 |
| expired | 是，衰减不归零 | 不补发旧到期提醒；新聊天明确提及旧事可按衰减分判断，说明已过期 |
| legacy、当前版本人工确认 | 是 | 保留原有提醒资格，不因legacy丢失；来源有效、勿扰等规则仍生效 |
| legacy、未确认 | 是 | 仅这部分旧记忆适用新审核规则 |
| stale/incorrect/superseded | 显式历史详情 | 否 |

拟议memory_candidate保存来源快照/粗提模型/保留倾向/状态；memory_ai_review保存证据哈希、审核模型、提示词和逐维结果；memory_lifecycle保存long/short、期限、宽限、解析状态和资格原因。保留现有memory_review、feedback、完整性status。旧确认只在版本和证据仍一致时继承，修订不继承。

粗提、审核各一份配置，各自模型code、接口、加密凭据引用和参数；审核与粗提实际模型快照不同，同一快照的别名不算不同。每请求冻结角色配置、参数、隐私指纹和提示词，走统一预算账本。统一资格函数覆盖入队、判断、关注触发、手动与后台发送，不能只在UI隐藏。

粗提保留v3过滤：长期价值事实；recent中近期可能再提起的有时效计划/安排/状态标short。每日问候、例行、玩笑仍跳过。window_age由系统计算，默认60天为old（可配置、未调优），old不输出短期；缺时间阻断。skip_reason仅在全空窗口填写。

审核给证据支持、类别、粗粒度期限、三个敏感布尔值、high/medium/low置信等级及一句原因。放行主要依赖supported和明确直接陈述，不用未经校准的数值置信阈值。敏感主动提醒须直接证据、粗提和审核两个不同模型对同一事实一致；结构合法不算语义一致。推断、主体不明或分歧只搜索、优先抽检。reported不因标签本身降级。没有逐条必须人工确认的日常流程。

## 本机日期规则（拟实现）

读取被引用原文、对应消息事件时间、版本和Asia/Shanghai时区；模型不输出date_expression，不计算绝对有效期，系统不发送精确消息事件时间让模型算“明天”。

| 表达 | 确定性规则 |
| --- | --- |
| 明天/后天 | 锚点本地日期加1/2天 |
| N天后 | 明确正整数加到锚点，超配置上限则unresolved |
| 下周X | 下一个自然周指定星期，周一为起点 |
| 周X | 本自然周且不早于消息日；否则不擅自滚周 |
| X号 | 当月有效且不早于消息日；跨月意图不清则unresolved |

多安排、多锚点冲突、非法日或不在范围内时，回退审核给的14/60天档位并标unresolved，仍锚定消息时间，不按入库日续命。不能据此发精确约定日推送；普通关联按粗粒度期限和其他资格判断。明确约定有效至当日本地日结束，再给五个完整本地日宽限，之后expired且降权非零；无明确约定日的14/60天不额外加五天。

确定性测试用合成原文和注入时钟：跨午夜/周日/跨年、同日周X和已过星期、月底X号、闰年和非法日、多个引用冲突、未知时间、修订使缓存失效、宽限第5天末/第6天、14/60天回退。相同输入与规则版本必须同结果，不依赖运行日期。

试点单独报告日期解析成功率和回退比例：以送入日期解析器的短期候选为总数，报告明确解析成功数、按14/60天回退数，以及因缺少事件时间无法建立期限的数量；各类分母与规则版本必须写明，不把无时间锚点算成成功。另报检测到日期表达的候选中解析成功的比例，避免大量无日期候选稀释覆盖问题。

首版暂不覆盖今晚、明晚、这周末、下个月、月底、过两天、大后天等表达，以及含糊或冲突的多日期安排。它们标unresolved并按审核给的14/60天档位、被引用消息事件时间回退，不猜测具体约定日，不触发精确到期提醒；未知事件时间时保留unresolved且不凭运行日补出有效期。不能把“大后天”中的“后天”等子串当成已支持表达，确定性用例须覆盖这些误命中。

## 权重、回填和曲线

保留temporal_kind，另加long/short。相关性乘保留权重和时间因子：长期1.0、短期0.6，约定前1–2天临期提升1.5倍；均未调优。宽限内正常，过期可按半衰期30天/下限0.1衰减，均未调优；错证据不享受非零下限。

历史窗口按事件时间从新到旧、ID稳定排序，冻结后入队。每100个连续排定窗口报告时间范围、实际调用/合法返回、空窗/隐私阻断、长期候选数和精修通过长期数；展示“每百窗长期候选数”曲线，保留分母与缺失。模型产出不等于用户确认价值。曲线用于用户/审阅者决定停止位置，不暗自删历史或抬预算。

## 阶段2

独立约定任务/outbox和去重键，发送仍检查期限、勿扰、冷却、确认继承和资格，不补发过期旧约定。现场有用/没用/不对按通道能力走受限回执，不假设机器人已有按钮。correct/low_value/outdated绑定版本/证据；不值得记、已过期、没用不当事实错误。每周约十条随机、敏感优先抽检，记录抽样层/概率。有效显式事实标签错误率超过默认5%时停止主动提醒、只搜索并显示分子/分母/原因；参数未调优，不把无反馈当无错，不据离线一致率自动恢复。

## 阶段3（可选）

有需要才做有序免费模型池，不提前抽象到阶段1。加入需用户确认用完即停和数据条款，默认每模型用所填额度90%，参数按模型独立。精确403 AllocationQuota.FreeTierOnly才标耗尽并交接，不计生成失败；其他4xx不重试。账本保留请求与保守占用，不清零费用绕闸门。按公开价估算并标免费额度预期实付0，不假设账号有额度、不转付费兜底。

## 三十窗口烟雾批

最多30窗，受全局/单批预算和余量约束。空窗率仅告警。合法结算率<90%、D3xx窗口失败率>20%等比率暂停条件在累计10个已结束窗口后才生效，之前只报样本数和告警；失败窗包含在分母，一个窗口多个D3xx只算一次失败，事件数另报。

单窗口Token超过基线两倍（基线暂2600，未调优）可立即暂停；预算不足或无法确认是否生成的未知用量仍按费用保护立即停，不以观察期放行。精确识别的免费额度耗尽排除质量率分母，仍保留账本占用。烟雾结果不自动开启长期回填或主动提醒。
