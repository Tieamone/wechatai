# 临时人工确认闸门

依赖记忆的主动提醒暂时只使用当前版本已人工确认、证据版本仍有效的 active 记忆。普通关联在排名截断前筛选；入队、模型判断队列、派送队列和实际发送前均检查资格。既有待发关联也受检查，不能通过手动发送绕过。

绑定未确认记忆的特别关注保留设置和历史，页面提示“请先确认关联记忆”，暂停触发和发送；确认当前版本后恢复资格。已接受通知保留去重记录，不因重新确认而重发。未绑定记忆的纯关键词关注继续工作。

普通搜索和用户主动回忆不受此闸门限制；`rank_candidates` 的默认只读调用仍返回全部有效候选，生产入队显式使用 confirmed_only。无需数据库升级。此临时规则将在两段式审核设计落地时另行迁移，当前没有实现 AI 审核放行。

测试使用合成记忆和假 sender，覆盖未确认可检索但不入队、旧关联手动发送拦截、重新打开核对后拦截、绑定关注保留、纯关键词关注继续、版本变化失去资格。未验证真实微信通知，没有启动真实数据工作台。
