# 工作台导航与退出行为

工作台采用左侧菜单，首页只显示运行概况、采集与通知开关和常用入口。

| 分组 | 页面 |
| --- | --- |
| 首页 | 运行概况 |
| 聊天与记忆 | 寻找历史、记忆库、人物资料 |
| 提醒中心 | 提醒与记录、特别关注 |
| 任务管理 | 新消息自动处理、历史初始化 |
| 设置与帮助 | 模型配置、隐私与映射、手工导入、使用帮助 |

切换页面保留当前搜索和未提交的表单。记忆证据仍默认折叠，可按需展开；确认正确的记忆移到已确认列表。

AI 正在处理时显示动态进度条，表示正在等待处理结果，不代表完成百分比。历史消息提炼覆盖条使用实际已提炼条数。系统启用减少动态效果时，页面关闭动画。

关闭浏览器标签页不会停止服务。关闭工作台命令行窗口或结束工作台后，采集和机器人会检测到所属工作台已退出并停止；已经提交的读取、模型请求或发送可能需要短暂收尾。重新打开工作台后，可从首页按需启动采集和机器人。

进程退出核验使用隔离数据库，覆盖正常退出和强制结束工作台两种情况，不读取真实微信、不发送手机通知。
