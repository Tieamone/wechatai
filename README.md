# 微信聊天记忆助手

个人使用的本地聊天记忆工作台：保存指定会话原文，整理带证据的记忆，在新消息与历史明确相关时通过微信机器人提醒本人。

## 当前功能

- Windows 固定账号和单联系人采集、历史导入与后续更新。
- 原文字面搜索、记忆提炼、证据查看、人工确认和更正。
- 兼容模型接口配置、新消息自动提炼、历史关联判断和自动调用次数限制。
- 关键词特别关注、普通关联提醒、微信机器人通用通知。
- 人物别名与历史号码、隐私替换、任务管理和运行开关。

## 使用与部署

源码不包含聊天记录、账号绑定、密钥或机器人登录状态，也不包含个人设备及验收记录。

1. 使用 Windows 和 Python、Node 环境，在项目根目录运行 `setup.cmd` 安装依赖并构建前端。
2. 机器人依赖另在 `tools/wechat-mcp` 执行 `npm ci --ignore-scripts` 和 `npm run build`。
3. 运行 `run.cmd`，自动打开本机浏览器并一次性登录；当前标签页刷新无需重抄令牌。自动打开失败时，访问 `http://127.0.0.1:8765`，使用启动窗口备用令牌登录。
4. 模型地址、模型名称和密钥在工作台设置；机器人由本人扫码登录。
5. 首次采集绑定需要本机账号目录、微信进程和联系人配置，尚无通用绑定向导。初次读取使用本机环境变量 `WECHAT_CONTACT_NAME` 指定联系人；已有绑定优先按本机保存的联系人标识核验。个人参数只保留在本机，不写入源码。

关闭工作台命令行窗口会停止采集和机器人；仅关闭浏览器不会停止后台。模型调用可能计费。手机只收到通用提醒，详情仍在电脑查看；没有 Android 详情客户端或自建转发服务器。

## 文档

通知策略在“设置与帮助 → 通知与备份”修改。默认入库新鲜度 5 分钟、发送有效期 15 分钟、未来时间容差 2 分钟；发送时按电脑本地时间执行 23:00–08:00 勿扰，同一记忆冷却 2 小时。被抑制的提醒保留卡片并显示原因，不集中补发。合成通知测试豁免这些规则。

超时补采文字可在“任务管理 → 新消息自动处理”建立历史范围，随后手动提炼。切换模块或把标签页放到后台会暂停相应轮询。数据库版本升级前自动备份，失败则停止升级，最多保留 5 份固定前缀的自动备份；这些是明文聊天副本，必须保留在本机非云同步目录，人工备份不参与清理。首次升级还应停掉所有后台并完整复制 `data/`。
